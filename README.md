 # Мій сайт

**Опублікований сайт:** [https://DmytroBabych-we.github.io/maintasks8/](https://DmytroBabych-we.github.io/maintasks8/)

## Сторінки

- `index.html`: головна (про мене, соцмережі, фото)
- `tasks.html`: завдання (таблиця множення)
- `team.html`: учасники моєї команди
- `style.css`: спільні стилі
